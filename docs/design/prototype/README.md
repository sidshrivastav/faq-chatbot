# Static Prototype

This directory contains a static high-fidelity Stage 2 prototype for the Configurable FAQ Knowledge Assistant.

## Files

- `index.html`: Single-page static prototype with all requested screens.
- `styles.css`: Visual styling, layout, responsive behavior, and state examples.
- `README.md`: Usage notes and prototype scope.

## Included Screens

1. Login
2. Admin Dashboard
3. FAQ Sources List
4. FAQ Source Detail
5. Chat Screen
6. Feedback State
7. Unanswered Questions Review
8. Analytics Dashboard

## Scope

This is a UI and interaction design prototype only. It does not include backend integration, API calls, database behavior, authentication logic, or production implementation.

The page uses realistic sample data and static examples of empty, loading, and error states where useful. Navigation links move between sections on the same page so reviewers can inspect layout intent quickly.

## How to View

Open `index.html` in a browser from this directory.
